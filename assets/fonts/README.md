# Bundled reading fonts

Original, unmodified TrueType fonts, embedded in enso for offline use on all platforms.
Regular, italic, bold and bold italic are included except for Fira Code, which
ships regular and bold (upstream does not provide italic faces).

- **Inter 4.1:** https://github.com/rsms/inter/releases/tag/v4.1 (`extras/ttf`).
- **Lora:** https://github.com/cyrealtype/Lora-Cyrillic (`fonts/ttf`).
- **JetBrains Mono:** https://github.com/JetBrains/JetBrainsMono (`fonts/ttf`).
- **Poppins:** https://github.com/google/fonts/tree/main/ofl/poppins.
- **Fira Code 6.2:** https://github.com/tonsky/FiraCode/releases/tag/6.2 (`ttf`).

Each family retains its original SIL Open Font License in `OFL.txt`.
`../font-licenses.txt` combines these notices for distribution with the app.
