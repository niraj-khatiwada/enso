# A little space for your thoughts.

Welcome to **enso**, a quiet home for your Markdown and text files.
This is a real Markdown file you can edit. Try **Ctrl+E** to switch between reading
and editing, or **Ctrl+\\** for split view. Your changes save automatically.
On macOS, the Command-key equivalents also work.

---

## Read. Write. Make room.

Your Markdown becomes a readable document, with headings, lists, tables,
quotes, and code. Use the **Edit** icon to work with the source, or **Split**
to see your changes alongside the page.

> Simplicity is the space where ideas take shape.

### Everything starts with a file

- **Open a file** to read any UTF-8 text document.
- **Open a folder** to explore your workspace and create notes.
- **New note** starts a Markdown file, wherever inspiration finds you.

Your files stay on your computer, in ordinary folders. Changes save automatically.

| Action | macOS | Windows / Linux |
| :--- | :--- | :--- |
| Open file | ⌘ O | Ctrl O |
| Open folder | ⌘ Shift O | Ctrl Shift O |
| New file | ⌘ N | Ctrl N |
| Close file | ⌘ W or Ctrl W | Ctrl W |
| Save | ⌘ S | Ctrl S |
| Edit / Read | ⌘ E or Ctrl E | Ctrl E |
| Toggle split | ⌘ \\ or Ctrl \\ | Ctrl \\ |
